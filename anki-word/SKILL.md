# Anki 智能单词卡工作流

## ✨ 核心特性

- **🎯 字段自适应**：自动检测 Anki 中"填空题"模型的字段名（支持 文字/正面/Text 等）
- **🔓 灵活校验**：可配置词源校验策略（strict/loose），支持词源不在词源卡组的情况
- **🔄 自动同步**：批量写入后自动触发 Anki 同步
- **🌐 中文输入**：支持中文单词（如"预言"）自动识别并查找对应的英文单词
- **🤖 智能近形词**：从 Anki 全库智能匹配近形词，不依赖固定词表

## 输入模式

1. **近形词积累**：普通单词列表（每行一张卡片）
2. **Q&A 积累**：行首带 `!` 的单词，生成问答卡
3. **整理卡片**：统一处理并批量写入 Anki

所有输入持久化到 `/home/pi/.openclaw/workspace/memory/repo/word-buffer.md`

## 配置（对话内记忆）

- `词源卡组`：用于提取词表（如"1-考研-英语单词"）
- `目标卡组`：近形词存放位置（如"1-考研-英语单词::7. 近形词"）
- `校验模式`：`strict`（词源须在卡组内）或 `loose`（无限制）
- `是否自动同步`：true/false

## 工作流

### 1. 解析输入
用户输入（示例）：
```
prophecy
farce
farcical
demonic
abridge
gratification
reap
linger
```

按行切分，每行 = 一张卡片。一行内的多个词用空格/逗号分隔，视为一组易混词。

### 2. 智能处理每个词
对于每行（一个或多个词）：
- **若输入是中文**：调用大模型知识或搜索 Anki 找到对应英文单词
- **查找近形词**：
  - 优先从 Anki 全库中搜索该词的近形词（衍生、读音相近、词型相近）
  - 若 Anki 中无，使用大模型语言知识生成候选近形词
- **生成释义**：词性 + 中文释义
- **生成记忆提示**：根据近形词关系类型（衍生/读音/词型）生成简短助记

### 3. 展示预览（近形词模式）
表格展示：
| 词源 | 正面预览 | 近形词 | 助记 |
|------|----------|--------|------|

用户可删除/修改某些行，确认后批量写入。

### 4. 写入 Anki
- 确保目标卡组存在
- 使用 `batch_create_notes` 一次写入
- **字段自适应**：通过 `get_note_type_info` 获取"填空题"模型的实际字段名（如 `文字`、`背面额外`）
- **卡片格式**：
  - 填空字段：`单词：{{c1::词性. 释义}}`
  - 背面字段：`助记：...`
- **写入后自动同步**：必须调用 AnkiConnect 的 `sync` 接口。**注意：`batch_create_notes` 与 `sync` 必须在同一个 Tool Call 批次或紧随其后的原子操作中执行，防止因回复过快导致同步指令被跳过。**

### 5. 完成反馈
- 确认 AnkiConnect 返回 `{"result": null, "error": null}` 后再显示成功
- 显示已创建数量、卡组名
- 提示同步状态
- 清空 buffer

## Q&A 模式
行首 `!` 标记的单词：
- 为每个词生成：`/IPA/` + 中文词义 + 英文例句 + 中文译注
- 使用 Basic 模型，卡片添加到日常卡组

## 近形词关系类型
| 类型 | 说明 | 示例 |
|------|------|------|
| 衍生 | 同词根/词缀派生 | prophecy → prophet |
| 读音相近 | 发音易混 | their / there / they're |
| 词型相近 | 拼写易混 | farce / farcical |

## 记忆提示角度
- 词源/词根：`pro-前 + phecy说 → 预言`
- 读音对比：`affect 重音在前，effect 重音在后`
- 拼写对比：`dessert 多一个 s = 甜点`
- 联想/谐音：`principal 校长是你的 pal`

## 原则
- ✅ 先展示、后写入
- ✅ 字段自适应（根据实际 Anki 配置）
- ✅ **原子化同步**：写入后强制触发同步，不完成不汇报
- ✅ 支持中文输入自动转换
- ✅ 词源校验可配置（默认 loose）
- ✅ 近形词智能匹配（Anki 库 + 大模型）

---

## 🛠 经验教训 (2026-03-20)
- **同步丢失风险**：在并发或链式工具调用时，如果 `sync` 指令未与写入指令强绑定，可能因会话状态更新而被丢弃。必须确保 `sync` 调用是“整理”环节不可分割的最后一步。

## 使用示例
**交互式对话**：
```
你: prophecy, farce
我: 已记录 2 个词到 buffer。词源卡组？目标卡组？
你: 词源：1-考研-英语单词，目标：1-考研-英语单词::7. 近形词
我: [展示预览表格]
    prophecy + prophet
    farce + farcical
    ...
你: 确认
我: ✅ 已创建 2 张卡片，Anki 已同步
```

**配置默认值**：
- 校验模式：loose（允许词源不在词源卡组）
- 自动同步：true
