# Skills

A collection of useful skills and workflows.

## Available Skills

### [anki-word](./anki-word/SKILL.md)

智能 Anki 单词卡工作流，支持近形词自动生成、中文输入识别、字段自适应和 Anki 同步。

**三种模式：**
- 📝 **近形词积累** — 普通单词列表，每行一张卡片
- ❓ **Q&A 问答卡** — 带 `!` 标记的单词，生成问答卡
- 📋 **整理卡片** — 统一处理并批量写入 Anki

**核心特性：**
- 🎯 字段自适应：自动检测 Anki 中"填空题"模型的字段名
- 🔄 自动同步：批量写入后自动触发 Anki 同步
- 🌐 中文输入：支持中文单词自动识别并查找对应英文
- 🤖 智能近形词：从 Anki 全库智能匹配近形词
